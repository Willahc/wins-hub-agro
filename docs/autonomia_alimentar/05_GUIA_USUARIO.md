# Autonomia Alimentar — Guia do Usuário

## Como usar

1. Acesse **Autonomia Alimentar** no menu lateral
2. Selecione a fazenda
3. Preencha o rebanho (quantidade, peso, consumo)
4. Adicione áreas de pastagem (se disponível)
5. Adicione estoques (silagem, feno, etc.)
6. Configure a planejamento (meta, data, margem)
7. Clique em **Calcular**
8. Revise o resultado
9. Clique em **Salvar cenário** para persistir

## Glossário

- **MS** = Matéria Seca
- **% PV** = Percentual do Peso Vivo
- **Autonomia** = Dias que o estoque sustenta o rebanho
- **Status Crítico** = Autonomia < 50% da meta
- **Status Atenção** = Autonomia entre 50% e 100% da meta
- **Status Adequado** = Autonomia ≥ meta

## Dicas

- O consumo % PV é editável — valores típicos: 2.0–3.0% para vacas em lactação
- Informe a % de utilização do pasto conforme o manejo real
- A % de aproveitamento do silo depende de perdas na retirada
- Use a margem de segurança para cenários conservadores
- Compare cenários salvos para decisões de compra/transferência

## Avisos

- O cálculo é **estimativo** — não substitui avaliação zootécnica
- Assume consumo constante ao longo do período
- Dados incorretos geram resultados incorretos
- Sempre valide com profissional habilitado
